Installer KTRX

Une ligne, sans droits administrateur. Le moteur est vérifié, installé dans votre dossier personnel et ajouté au PATH.

Rien à installer d'autre.

Pas de runtime, pas d'OpenSSL, pas de Visual C++. Le binaire fonctionne sur une machine neuve.

Vérifié avant installation.

L'installateur compare l'empreinte SHA-256 du fichier avec celle publiée ici, et s'arrête au moindre écart.

Mise à jour en une ligne.

Relancez la même commande pour passer à la dernière version. Vos outils installés sont conservés.

Téléchargement manuel

Si vous préférez placer le binaire vous-même dans un dossier de votre PATH.

Vérifier une archive

Comparez l'empreinte affichée sous chaque archive avec celle de votre fichier :

Fichier téléchargé avec un navigateur ? Les binaires KTRX ne sont pas encore signés par Apple ni Microsoft. macOS peut refuser de les ouvrir et Windows afficher un avertissement SmartScreen. L'installation en une ligne ci-dessus n'est pas concernée. Voir Dépannage.

Configuration requise

  • Windows 10 ou 11, 64 bits. Sur un PC ARM, la version x64 fonctionne grâce à l'émulation de Windows 11.
  • macOS 10.15 ou plus récent. Les versions 0.9.x sont compilées pour Intel : elle fonctionne sur Apple Silicon grâce à Rosetta 2. Une version universelle suivra.
  • Linux x86_64 ou ARM64, n'importe quelle distribution (binaire statique).
