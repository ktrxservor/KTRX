Documentation

Tout ce qu'il faut pour installer KTRX et utiliser ses outils.

Démarrer

KTRX est un moteur qui exécute des outils : de petits programmes WebAssembly spécialisés (inspection HTTP, audit d'en-têtes, conversion Base64…). Le moteur s'installe une fois ; les outils se téléchargent à la demande depuis le catalogue.

Trois commandes suffisent :

# 1. installer le moteur (macOS, Linux)
curl -fsSL https://ktrx-site.tiagoantunes2009.workers.dev/install.sh | sh
# 2. installer un outil
ktrx install thoth
# 3. le lancer
ktrx run thoth --encode "Bonjour"

Sous Windows, la première commande se lance dans PowerShell : irm https://ktrx-site.tiagoantunes2009.workers.dev/install.ps1 | iex.

Installer KTRX

macOS et Linux

Dans le Terminal :

curl -fsSL https://ktrx-site.tiagoantunes2009.workers.dev/install.sh | sh

Sans curl (Alpine, certaines distributions minimales) : wget -qO- https://ktrx-site.tiagoantunes2009.workers.dev/install.sh | sh.

Windows

Dans PowerShell (menu Démarrer › « PowerShell ») :

irm https://ktrx-site.tiagoantunes2009.workers.dev/install.ps1 | iex

Ce que fait l'installateur

  • il détecte votre système et votre processeur (Windows x64, macOS Apple Silicon ou Intel, Linux x86_64 ou ARM64) ;
  • il télécharge le moteur et vérifie son empreinte SHA-256 ; au moindre écart, il s'arrête sans rien installer ;
  • il place ktrx dans ~/.ktrx/bin (%USERPROFILE%\.ktrx\bin sous Windows), sans droits administrateur ;
  • il ajoute ce dossier à votre PATH. Ouvrez un nouveau terminal pour que ktrx soit reconnu.

Options

VariableEffet
KTRX_VERSION=0.8.0installe cette version au lieu de la dernière
KTRX_INSTALL=/cheminautre dossier d'installation (le moteur va dans bin/)
KTRX_NO_MODIFY_PATH=1ne modifie pas le PATH

Pour une installation manuelle, les archives et leurs empreintes sont sur la page Télécharger.

Installer des outils

CommandeEffet
ktrx searchliste le catalogue ; ktrx search hash filtre
ktrx install anubisinstalle la dernière version (accepte aussi K~ANUBIS)
ktrx install anubis@1.1.0installe une version précise
ktrx uiouvre l'interface graphique dans le navigateur
ktrx listoutils installés et leur version
ktrx updatemet à jour tous les outils ; ktrx update anubis pour un seul
ktrx uninstall anubissupprime l'outil
ktrx info anubisdescription, version, permissions, exemples

Les outils sont rangés dans ~/.ktrx/tools (variable KTRX_HOME pour un autre dossier, ou --dir). Chaque téléchargement est vérifié avant d'être écrit : empreinte SHA-256 publiée par le catalogue, archive valide, version du moteur compatible. Si une vérification échoue, rien n'est installé.

Lancer un outil

ktrx run <outil> [arguments]

Chaque outil décrit ses arguments avec ktrx run anubis --help. La page de chaque outil, dans le catalogue, détaille aussi ses arguments, ses valeurs admises et des exemples prêts à copier.

Résultat

Un outil renvoie du JSON, affiché joliment dans le terminal. Options du moteur, à placer après le nom de l'outil :

  • --json : JSON sur une seule ligne, pratique pour un script ;
  • --events : progression puis résultat en JSON, une ligne par événement.

Un outil long affiche sa progression. Ctrl+C l'interrompt proprement. On peut aussi lancer une archive directement : ktrx run ./K~THOTH.tool --encode "Bonjour".

Interface graphique

Vous préférez cliquer à taper ? ktrx ui ouvre une page dans votre navigateur pour tout faire : parcourir le catalogue, installer, mettre à jour et supprimer des outils, puis les lancer avec un formulaire.

ktrx ui

La commande démarre un petit serveur qui n'écoute que sur votre ordinateur (127.0.0.1, port 4747 ou un port libre) et ouvre la page. Ctrl+C dans le terminal l'arrête. L'interface suit le thème clair ou sombre de votre système.

Mes outils et catalogue

« Mes outils » liste ce qui est installé et signale les mises à jour disponibles ; « Catalogue » propose tous les outils, avec recherche, filtres par catégorie et leurs permissions. Un clic sur Installer ou Mettre à jour lance la même commande que le terminal, avec la même vérification SHA-256.

Lancer un outil

Chaque outil a sa page : un formulaire est généré à partir de ses arguments (champs requis, interrupteurs, nombres, sélecteur de fichiers), puis le résultat s'affiche en JSON coloré, avec copie et téléchargement. Un outil long montre sa progression et peut être annulé.

Les permissions restent les vôtres

Rien n'est assoupli : avant chaque exécution d'un outil qui déclare des permissions, une fenêtre les liste et rien ne démarre sans votre accord, valable pour cette seule exécution. Les écritures restent dans le dossier que vous choisissez, et un outil qui lance des programmes ne peut lancer que ceux que vous cochez (ou, s'il ne les limite pas, que si vous l'autorisez explicitement).

Sécurité du serveur local

  • il n'écoute que sur la boucle locale : aucune autre machine ne peut s'y connecter ;
  • chaque lancement génère un jeton aléatoire, transmis au navigateur dans le fragment de l'adresse (jamais envoyé sur le réseau) et exigé pour toute action ;
  • les en-têtes Host et Origin sont contrôlés, ce qui empêche un autre site web d'agir à votre place.

Disponible depuis KTRX 0.9 : relancez la commande d'installation pour mettre le moteur à jour.

Permissions

Un outil n'a accès à rien par défaut. S'il a besoin du réseau, de fichiers ou de programmes, il le déclare, et KTRX vous le demande à chaque exécution :

K~HERMES requests network access for this run. Allow? [y/N]
PermissionCe qu'elle autorise
Réseauconnexions DNS, TCP, TLS et UDP vers la cible donnée en argument
Lecture de fichierslire les fichiers et dossiers que vous désignez
Écriture de fichiersécrire uniquement dans un dossier choisi (--write-dir, sinon le dossier courant)
Réseau bas niveauping ICMP, ARP, sondes TCP ; peut demander des droits administrateur
Programmeslancer des programmes de votre machine, avec vos droits ; la liste est affichée avant d'accepter

Options de ktrx run, avant le nom de l'outil

  • -y : accepte d'avance les permissions déclarées par l'outil (utile dans un script) ;
  • --write-dir DOSSIER : le seul dossier où l'outil pourra écrire ;
  • --allow-program NOM : restreint les programmes qu'il pourra lancer (répétable).

Hors d'un terminal interactif (script, tâche planifiée), sans -y, toutes les permissions sont refusées.

Sécurité

  • Isolation. Chaque outil s'exécute dans un bac à sable WebAssembly, sans accès implicite au disque, au réseau, aux variables d'environnement ni au système, avec une mémoire limitée.
  • Accès accordés une fois. Une permission vaut pour une seule exécution et seulement pour ce que l'outil a déclaré.
  • Programmes. La permission « Programmes » est la seule qui sort du bac à sable : un programme lancé a vos droits. Chaque lancement est affiché, et tout ce qu'un outil a démarré est arrêté avec lui.
  • Téléchargements vérifiés. Moteur et outils passent par HTTPS et sont contrôlés par empreinte SHA-256 avant d'être installés.
  • Publication. Seule l'équipe KTRX publie des outils dans le catalogue ; chaque publication est tracée.
  • Limite actuelle. Les binaires ne sont pas encore signés par Apple ni Microsoft ; voir Dépannage si vous les téléchargez avec un navigateur.

Un problème de sécurité ? Signalez-le sur GitHub.

Assistants IA

ktrx mcp met les outils à disposition d'un assistant (Claude Code, Codex, Gemini CLI, Cursor…) par le protocole MCP. Enregistrez-le une fois, par exemple pour Claude Code :

claude mcp add --scope user ktrx -- ktrx mcp

L'assistant dispose alors de trois actions : chercher un outil, lire ses arguments, le lancer. Les résultats sont en JSON. Les permissions accordées sont fixées par vous, une fois, avec --allow (par défaut network, file-read et file-write ; raw-net et process sont refusées). Les écritures restent dans ~/.ktrx/workspace, ou dans le dossier de --write-dir. Détails et commandes pour chaque assistant : Pour les IA.

Mettre à jour, désinstaller

Mettre à jour

Le moteur : relancez la commande d'installation. Les outils : ktrx update, ou le bouton « Tout mettre à jour » de l'interface graphique.

Désinstaller

macOS et Linux : rm -rf ~/.ktrx, puis retirez les lignes précédées de # KTRX dans ~/.zshrc, ~/.bashrc ou ~/.profile.

Windows (PowerShell) : Remove-Item -Recurse -Force $env:USERPROFILE\.ktrx, puis retirez %USERPROFILE%\.ktrx\bin du PATH utilisateur (Paramètres › « Modifier les variables d'environnement pour votre compte »).

Dépannage

« ktrx : command not found » ou « n'est pas reconnu »

Ouvrez un nouveau terminal : le PATH mis à jour n'est lu qu'à l'ouverture. En attendant : ~/.ktrx/bin/ktrx (macOS, Linux) ou %USERPROFILE%\.ktrx\bin\ktrx.exe.

macOS refuse d'ouvrir ktrx

Seulement si vous avez téléchargé l'archive avec un navigateur. Utilisez l'installation en une ligne, ou retirez la mise en quarantaine : xattr -d com.apple.quarantine ~/chemin/vers/ktrx.

Windows affiche « Windows a protégé votre ordinateur »

Seulement pour un fichier téléchargé avec un navigateur : « Informations complémentaires » › « Exécuter quand même », ou utilisez l'installation en une ligne. Vous pouvez vérifier l'empreinte sur la page Télécharger.

Derrière un proxy d'entreprise

KTRX utilise les variables HTTPS_PROXY, HTTP_PROXY et NO_PROXY : export HTTPS_PROXY=http://proxy.exemple:8080.

« aucune version de KTRX n'est publiée pour cette machine »

Votre système ou processeur n'est pas pris en charge. KTRX existe pour Windows x64, macOS 10.15+ et Linux x86_64 ou ARM64.

« ktrx ui » : la page ne s'ouvre pas, ou « Session expirée »

Si aucun navigateur ne s'ouvre, copiez l'adresse affichée dans le terminal (elle contient le jeton de cette session) ou relancez avec --no-open. « Session expirée » ou « Connexion perdue » veut dire que ktrx ui a été arrêté ou relancé : relancez-le et ouvrez la nouvelle adresse. Si le port est pris, choisissez-en un autre avec --port.

macOS avec une puce Apple Silicon

Les versions 0.9.x du moteur sont compilées pour Intel et fonctionnent sur Apple Silicon grâce à Rosetta 2 (softwareupdate --install-rosetta s'il n'est pas installé). Une version universelle suivra.

« this tool requires KTRX X.Y.Z or newer »

L'outil a besoin d'un moteur plus récent : relancez la commande d'installation pour mettre KTRX à jour.

Usage responsable

KTRX réunit des outils d'analyse et de test. Les outils qui contactent un service ou un hôte ne doivent viser que des systèmes que vous possédez ou que vous êtes explicitement autorisé à tester. Respectez la loi et les règles des services concernés. Chaque outil borne sa portée et explique ses limites sur sa page ; lisez-la avant de l'utiliser.

Vous développez des outils pour KTRX ? La publication est réservée à l'équipe : elle passe par un outil dédié et un mot de passe. Le moteur public, lui, sert uniquement à installer et exécuter des outils.
