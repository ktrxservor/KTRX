# K~HECATE — Hex Codec
> Hécate, déesse grecque des carrefours : cet outil convertit du texte et des octets entre UTF-8 et hexadécimal.

Convert pasted request fragments, payloads, or text to and from hexadecimal. Decoding accepts optional spaces and `0x` prefix and requires valid UTF-8 output.

```sh
ktrx run 'tools/HECATE ( Hex-Codec )/K~HECATE.tool' --encode 'GET / HTTP/1.1'
ktrx run 'tools/HECATE ( Hex-Codec )/K~HECATE.tool' --decode '474554202f'
```
